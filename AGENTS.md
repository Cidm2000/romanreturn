# Agent operating rules

Before substantive work, read `AUTORUN_PROTOCOL.md` and treat it as the binding default for autonomy, whole-product completion, question thresholds and definition of done.

Own the requested outcome rather than only the literal ticket. Decide ordinary reversible questions yourself. Consider the full finished result proportionally across UX, backend/data, security/privacy, reliability, accessibility, performance, testing, operations and maintainability. Continue autonomously until useful work is exhausted or a genuine hard stop is reached.

Inspect `README.md`, relevant docs, tests, config and existing patterns before consequential changes. Repository-specific constraints remain binding and may be stricter than the generic protocol.
